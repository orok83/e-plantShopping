# 🌿 Paradise Nursery - E-Plant Shopping Cart

**Live Demo:** [View the Project](https://orok83.github.io/e-plantShopping/)

## 📖 Introduction

Welcome to **Paradise Nursery**, an online plant shop built as a final React project. This application features a functional **shopping cart system** for houseplants, allowing users to explore, select, and manage their favorite plants with ease.

This project demonstrates a variety of modern front-end development techniques using **React**, **React Hooks**, and **Redux Toolkit**.

---

## 🚀 Features

* **Landing Page**
  A welcoming homepage with a button directing users to the plant catalog.

* **Navigation Bar**
  Persistent navigation links to:

  * Landing Page
  * Product Listing Page
  * Shopping Cart

* **Product Listing Page**

  * Displays a collection of plant cards including:

    * Plant image
    * Name & Description
    * Cost
    * "Add to Cart" button
  * Organized into at least two categories:

    * e.g., *Aromatic Plants*, *Medicinal Plants*

* **Shopping Cart Page**

  * Displays selected products with:

    * Thumbnail preview
    * Unit price and total cost
    * Quantity controls (increase/decrease)
    * "Delete" button to remove item
  * Includes:

    * “Continue Shopping” button
    * “Checkout” button
  * Dynamic cart icon updates in the navbar with total item quantity.
